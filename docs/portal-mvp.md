# Клиентское приложение Prive — план MVP

Отдельное приложение для клиентов салона: мастера и их работы, услуги с ценами,
онлайн-запись прямо в журнал YClients, «Мои записи», позже — отзывы.
Решения согласованы с Антоном 28.09.2026.

## Устройство

- **Отдельный процесс** `portal/` в этом же репо, свой systemd-юнит, порт 3021.
  В нём только публичные маршруты — админских (`/api/*` из `server.js`) нет физически,
  поэтому ошибка в портале не открывает клиентскую базу CRM.
- Общий код: `src/yclients.js` (цепочка `book_staff → book_services → book_dates →
  book_times → createRecord`, проверена в админской записи), `src/db.js` (WAL уже включён —
  два процесса на одной SQLite нормально).
- **Свой домен** без слова «crm», поддомен сайта салона (решить с Антоном).
- **PWA**, а не приложение в сторах: ставится иконкой на экран, ссылку можно дать в SMS,
  соцсетях, QR на ресепшене.

## Имена клиентов: два слоя

| | Что | Кто видит |
|---|---|---|
| Карточка YClients | внутреннее имя, комментарии админов | только админы |
| `portal_users` | подтверждённый телефон, имя «Как к вам обращаться?», которое ввёл сам клиент | клиент |

- Карточку ищем по последним 10 цифрам телефона (как `cardInCompany` / дедуп по человеку).
- Запись в YClients: если карточка есть — `id` + телефон + **текущее имя из YClients без
  изменений** (карточку не переписываем); если нет — имя, которое ввёл клиент.
- В комментарий записи — «Онлайн-запись (приложение)»: админ видит источник, «Обзор» считает канал.
- Все ответы портала — **по белому списку полей**. Никогда не отдаём: имя и комментарий из
  YClients, комментарий записи, `free_client`, `do_not_call`, VIP, заметки о звонках.
- Проверить шаблоны SMS-напоминаний YClients: подстановка имени клиента там — та же утечка.

## Вход

Push не годится для первого входа: подписка привязана к браузеру, а не к номеру, и не
доказывает, что человек владеет телефоном. Поэтому:

1. **Первый вход — Call me**: клиент вводит номер, приложение показывает номер, на который
   нужно позвонить; звонок сбрасывается (для клиента бесплатно), провайдер присылает нам
   webhook «номер подтверждён». Звонит сам клиент, поэтому блокировка немаркированных
   исходящих вызовов (операторы включили её в августе 2026) нас не касается.
2. **Запасной путь — SMS с кодом**, только кнопкой «Не получается позвонить».
   Дорого и непредсказуемо (см. тарифы ниже), поэтому не основной.
3. **Flash call (звонок-сброс нам → клиенту) не используем**: это исходящий автоматический
   вызов, с 2025 года нужна платная маркировка, без неё с августа 2026 операторы блокируют.
4. После подтверждения — **сессия на устройстве на год** (httpOnly-кука).
5. **Вход на новом устройстве**: если у клиента есть устройство с включённым push — туда
   приходит «Это вы входите? Да / Нет»; иначе снова Call me.

Защита: не больше 5 попыток подтверждения на номер в час и 20 на IP, код/сессия
подтверждения живёт 5 минут.

## Push (Web Push, VAPID)

Бесплатно, заменяет SMS после первого входа:
- напоминание о записи за сутки и за 2 часа;
- запрос оценки после визита (этап 2);
- «пора обновить» по ритму клиента (`avg_interval_days` уже считается для обзвона).

Ограничение iOS: push работает только если сайт добавлен на экран «Домой» (iOS 16.4+) —
приложение должно подсказывать это при первом входе с айфона.

## Запись

- Слоты — живые из `book_*`, справочники мастеров/услуг кэшируем на 10 минут.
- `save_if_busy: false` — занятый за секунду до клиента слот даёт понятную ошибку.
- Не больше 3 будущих записей на телефон; частота запросов ограничена.
- Клиенты с частыми неявками — без мгновенной записи («позвоните в салон» или «ожидает
  подтверждения»).
- Отмена клиентом — не позже чем за N часов (N решает Антон).
- После создания — `sync.importRecord`, чтобы запись сразу была видна в CRM.

## Портфолио

- Таблицы `staff_profiles` (описание, фото мастера) и `staff_works` (фото работ, подпись,
  услуга), ключ — `staff_id` YClients + `company_id`.
- Файлы — Yandex Object Storage (там же, где бэкапы), сжатие при загрузке.
- Загрузка — новый раздел «Мастера» в CRM.

## Этапы

1. **MVP**: каркас `portal/`, вход Call me + SMS-запасной, профиль с именем, мастера с
   портфолио, услуги с ценами, запись, «Мои записи» + отмена, push-напоминания,
   раздел «Мастера» в CRM.
2. **Отзывы**: только после визита с отметкой «пришёл», модерация, оценка ≤3 → задача
   админу (новый тип в `rules.js`) + Telegram владельцу.
3. **Удобства**: «повторить запись», любимый мастер, мини-приложение в мессенджере.

## Тарифы на подтверждение номера (собрано 28.09.2026)

| Способ | Цена за подтверждение | Для клиента | Риски |
|---|---|---|---|
| **Call me** (клиент звонит сам) | ~0,25–1 ₽ | бесплатно | почти нет; у SMS.RU старый вариант помечен «устарел» — провайдера брать с живым API |
| Flash call (звонок нам → клиенту) | ~0,2–1,5 ₽ + маркировка ~0,3 ₽ | ничего не делает | немаркированные автоматические вызовы операторы блокируют с августа 2026 |
| Telegram Gateway (код в Telegram) | $0,01 (~1 ₽), за недоставленные — возврат | нужен Telegram | оплата только в TON; статус Telegram в РФ нестабилен |
| SMS с кодом | ~3–5 ₽ | ничего не делает | МТС: до 66 ₽ за первое SMS абоненту в месяц с одного имени отправителя; у мелких отправителей бывали счета до 45 ₽ за SMS |

Провайдеры Call me: SMS.RU, СМС-Агент (CallMe), ProstoSMS (Wait Call), Unibell,
Telediscount (B-Calls). Выбирать по: живой API с webhook, оплата по счёту для ИП/ООО,
тестовый баланс. Точные цены — в личном кабинете при регистрации, на сайтах они «от».
